PLAIN-ENGLISH GLOSSARY

Before the lessons, the vocabulary.

Ten words you'll see everywhere on this site — in one honest sentence each.

{ }The foundation

Programming

The general practice of writing instructions a computer can follow. Every language below is one way of doing it.

$The command line

Terminal

The text window where you control your computer by typing — files, installs, and running your code.

</>HyperText Markup Language

HTML

Structures a page's content — headings, paragraphs, links, images — without deciding how any of it looks.

#Cascading Style Sheets

CSS

Controls how that structure looks: color, spacing, layout, fonts, and motion.

JSA programming language

JavaScript

Makes a page interactive — reacting to clicks, updating content, and talking to servers.

PYA programming language

Python

Known for clean, readable syntax — used for scripting, data work, and backend applications.

SQLStructured Query Language

SQL

How you ask a database for data — fetch it, filter it, sort it, or change it.

WEBHow it all ships

The Web

Browsers, servers, HTTP and DNS — and the hosting that puts your finished work on the internet.

GITA version control system

Git

Tracks every change to your code over time, so you can collaborate safely and never lose work.

⚒The proof

Projects

Twelve real applications — quiz games, trackers, kanban boards, API apps — built and explained step by step.

THE METHOD

Every lesson follows the same learning loop, with enough explanation to understand why the code works.

STEP 1

Definition first, then a plain-language explanation and a visual mental model.

STEP 2

STEP 3

Complete a practical task, solve the challenge, and turn lessons into projects.
